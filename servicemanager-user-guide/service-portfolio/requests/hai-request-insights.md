# HAi Request Insights

HAi Request Insights provides real-time insights for the selected request, including similar resolved requests and recommended knowledge articles.

![HAi Request Insights](/_books/servicemanager-user-guide/service-portfolio/requests/images/hai-request-insights.png)

## Accessing HAi Insights

When viewing a request record, an HAi Insights icon is available on the right-hand sidebar. Selecting this icon opens the HAi Insights panel, which contains the following sections:

![HAi Insights icon](/_books/servicemanager-user-guide/service-portfolio/requests/images/hai-insights-icon.png)

* **Next suggested action**: HAi analyzes the request and suggests the next action to take.
* **Request summary**: A simplified summary of the request that shows who raised the request and a brief overview of what the request is about.
* **Suggested requests**: HAi looks for requests similar to the one being viewed. Reviewing the information in these requests may help lead to a resolution or highlight a need to link the requests.
* **Suggested articles**: HAi looks for knowledge articles that might help with the request by providing potential solutions.
* **User's open requests**: HAi lists the other requests that the user has raised. This may reveal similar requests that have already been raised, or show that the user has a large number of outstanding requests that might need attention.

## Action history

The Action History option allows you to review the history of suggested next actions provided by HAi Insights for a request. This helps analysts understand previous recommendations and review how they have been handled throughout the lifecycle of the request.

### Viewing the action history

1. Open a request in Service Manager.
2. Open HAi Insights from the right-hand sidebar.
3. Locate the **Suggested Next Action** section.
4. Select the **More actions** (three-dot) menu.
5. Select **Action History**.

### Using the action history

The action history provides additional context when reviewing the current suggested next action. It can be useful when taking ownership of an existing request, reviewing progress, or determining what further action is required.

When reviewing a suggested next action, the following options are available:

* **Apply**: Apply the suggested action to the request.
* **Mark as Actioned**: Indicate that the suggested action has been addressed.
* **Mark as not Relevant**: Indicate that the suggested next action is not relevant to the request.

The Action History complements the request Timeline by focusing on the recommendations provided by HAi Insights rather than the general history of updates to the request.
