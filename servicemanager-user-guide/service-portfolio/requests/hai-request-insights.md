# HAi Insights

The HAi Request Insights provides real-time insights for the selected request, including similar resolved requests and recommended knowledge articles.

![HAi Request Insights](/_books/servicemanager-user-guide/service-portfolio/requests/images/hai-request-insights.png)

## Accessing HAi Insights

When viewing a request record, an HAi Insights icon will be available on the right-hand bar. Selecting this icon will pop out the HAi Insights panel.

![HAi Insights icon](/_books/servicemanager-user-guide/service-portfolio/requests/images/hai-insights-icon.png)

* **Next suggested action**: HAi will analyze the request and provide a suggested action that should be done next.
* **Request summary**: A simplified summary of the request that shows who raised the request and a brief overview of what the request is about.
* **Suggested requests**: HAi will look for similar requests to the one being viewed. Reviewing the information in the other requests may help lead to a resolution or prompt the need to link the requests.
* **Suggested articles**: HAi will look for knowledge articles that might help with the request, providing potential solutions.
* **User's open requests**: HAi will list the other requests that the user has raised.  This may result in the discovery of similar requests already raised or just identifying that a customer has a large number of outstanding requests that might need some attention.
