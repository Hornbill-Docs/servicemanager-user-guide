# Approvals

Approvals are used to manage the lifecycle of knowledge articles, ensuring that changes are reviewed and approved before they are published. This helps maintain the quality and accuracy of the knowledge base.

![Approval List](/_books/servicemanager-user-guide/knowledge/images/approval-list.png)

This view offers a list of all knowledge articles that are pending approval, across all of the knowledge bases, along with their current status and the assigned approvers. Users can filter the list by various criteria, such as article type, status, or assigned approver.

Approvals can be actioned either individually or in bulk. When an article is approved, it moves to the status to being published, while rejected articles remain as draft and sent back to the author for revisions.

## List configuration

Selecting the cog icon in the tool bar will open the list configuration.

* **Visibility**: Select each column that will be visible in the list.  A mobile icon is available next to each column name that allows you to hide the column when viewing the list on small screens.
* **Order**: Drag and drop the columns into the order to be displayed in the list.
* **Settings**: Set the row density and how many records to display per page.
