# Browse Knowledge

This view is shared by all Knowledge users as a place to find and read the Knowledge content that is available to them. From here, you can browse through knowledge bases by topic, or use the search bar to find specific articles.

![Search and Browse Knowledge](/_books/servicemanager-user-guide/knowledge/images/search-browse.png)

## Before you begin

To access the Search/Browse view:

* You must have the [Knowledge User Role](/servicemanager-config/setup/service-manager-roles#knowledge-roles) assigned to your Hornbill account.
* You must have access to at least one active knowledge base.

## Accessing the Browse view

Depending on the user's Knowledge role, browsing a knowledge base can be accessed in different ways.

### Service Manager and Platform users

If you have a subscription to use the Service Manager application or the platform, you can access **Browse** from the Knowledge option under the Service Manager application menu.

 1. In the left-hand menu bar, navigate to **Service Management** > **Knowledge**.
 1. Click **Browse**.
 1. Select a knowledge base.
 1. Expand the topic structure to view the articles that sit under each topic.
 1. Select an article to view its content.

### Basic users

Users with a basic user account can access the **Browse** view from the Employee Portal.

**To access Browse as a basic user:**

 1. Log in to the Employee Portal.
 1. In the top horizontal bar, click **Knowledge**.

    ![Knowledge button in top bar](/_books/servicemanager-user-guide/knowledge/images/knowledge-option-top-bar.png)

    :::tip
    Using [the Links widget](/esp-config/customize/employee-portal/employee-portal-widgets#links-widget), an Employee Portal designer can create an easy-to-access link to Knowledge that can be added to any page.
    :::

## Search Knowledge from within Browse/Search

The search bar in the top right of the **Browse** view allows you to search for articles across all knowledge bases that you have access to. You can search by keywords or tags.

**To search the knowledge bases:**

1. On the search bar, select to search on either keywords or tags.
1. Select the search text box to enter your search query.
1. In the Search box, enter your search text.
1. The results page will display a list of articles that match your search query.
1. Select an article to view.

### Search results

The list of search results includes links to the relevant articles as well as the following information:

* The name of the knowledge base that the article belongs to.
* The article title.
