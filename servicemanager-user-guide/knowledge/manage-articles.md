# Manage Articles

The Manage Articles page lists, in one view, all the articles from every knowledge base that you own or can contribute to.

![Manage Articles page](/_books/servicemanager-user-guide/knowledge/images/manage-articles-list.png)

## Breadcrumb

![Breadcrumb](/_books/servicemanager-user-guide/knowledge/images/manage-articles-breadcrumb.png)

A breadcrumb is shown at the top of the page, with the *Knowledge* link that takes you to the [Knowledge Overview](/servicemanager-user-guide/knowledge/overview). A back button is also shown, which returns you to the previous page that you were viewing.

## Toolbar

### Filters

The default view of articles shows all active articles from all knowledge bases that you have access to. Active articles are those that have not been retired. Any changes to the filters are maintained while you have an active Hornbill session. If you log out and log back in, the filters will reset to the default view.

* **Keyword and Tag filter**: This filter allows you to search for articles by keywords or tags. The search is performed across all knowledge bases that you have access to. You can enter multiple keywords or tags separated by commas, and the results will include articles that match any of the entered terms.
* **Knowledge base filter**: This filter defaults to *All Knowledge Bases*. Each user can select from the list of knowledge bases that they have access to, either as an owner or a contributor. If a knowledge base is selected from the list, the articles displayed will be limited to that knowledge base.
* **More filters**: This button opens a set of additional filters that allow you to further refine your search results. These include criteria such as article status, article type, and a selection of date ranges. You can combine multiple filters to narrow down the list of articles displayed.

### New article

![New Article button](/_books/servicemanager-user-guide/knowledge/images/new-article-button.png)

The **New Article** button opens the new article page, where you can create a new article. If a specific knowledge base has already been selected in the knowledge base filter, the new article will be added to that knowledge base. Otherwise, the new article page asks which knowledge base to use.

### List configuration

The list configuration is accessed by clicking on the cog icon in the toolbar.

* **Visibility**: Select the columns to display in the article list. You can choose from a variety of columns, such as article title, knowledge base, status, and more. The selected columns will be displayed in the article list, allowing you to customize the view to your preferences.
* **Order**: Select the order in which the columns are displayed in the article list. Each column can be dragged and dropped into the desired position. A number is displayed next to each column name to indicate its position.
* **Settings**: Choose the row density and the number of rows to display per page. The row density can be set to *Compact* or *Expand*.

## Article list

The article list displays the articles that match the current filter criteria. Each article is displayed in a row, with columns showing information such as the article title, knowledge base, status, and more. You can click an article title to view or edit the article.

Depending on the number of rows displayed per page, the list may be paginated. You can navigate between pages using the pagination controls at the bottom of the list.
